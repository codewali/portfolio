# Portfolio Redesign Plan - MoMA Modern Art Aesthetic

## Design System

### Colors (Eclectic & Harmonious)
- Cream: #FAF7F2 (background)
- Charcoal: #2A2A2A (primary text)
- Terracotta: #D4745E (accent 1)
- Sage: #8A9B68 (accent 2)  
- Dusty Pink: #E5A8A8 (accent 3)
- Warm Ochre: #E8B84F (highlight)

### Typography (Dairy Boy Style)
- Display: Playfair Display (elegant serif) - LARGE & BOLD
- Script: Caveat (cursive accents)
- Body: Inter (clean sans)
- Sizes: Much larger, more impactful

### Animations (Untitled UI Level)
- Smooth scroll
- Fade-in on viewport
- 3D transforms on hover
- Parallax backgrounds
- Micro-interactions

### Content Strategy (Industry-Agnostic)
- Focus on PROBLEMS SOLVED (not B2B context)
- Universal language
- Show the work, not the industry

## Implementation
1. New color system with CSS variables
2. Add Google Fonts (Playfair Display, Caveat, Inter)
3. Animation library with scroll triggers
4. Reframe all content
5. Minimalist, editorial layout
6. Light mode default, dark mode optional
